Este projeto consiste na modelagem e implementação orientada a objetos (POO) de um sistema inspirada no universo Pokémon, desenvolvido em Java. 
O objetivo principal é aplicar conceitos avançados de Programação Orientada a Objetos, como encapsulamento, herança, polimorfismo e manipulação de classes estruturadas.

Estrutura do Projeto:

O código-fonte está organizado em pacotes que dividem as responsabilidades do sistema:

- main: Contém a classe principal (Main.java) responsável por iniciar a aplicação e simular os fluxos do jogo.
- model: Agrupa as classes de domínio que moldam as regras de negócio:
- Pokémon: Define os atributos (como vida, nível e tipo) e comportamento dos pokemons.
- Treinador: Gerencia o perfil do jogador, sua equipe de Pokémon e inventário.
- Habilidade: Modela os ataques e poderes utilizados durante os confrontos.
- Batalha: Controla a lógica de turnos, danos e interações de combate entre os Pokémon.
- Item / ItemCura / ItemEvolucao: Representam os artefatos utilitários que podem ser consumidos ou aplicados para recuperar a vida ou evoluir os Pokémon.


Tecnologias Utilizadas:
Java (JDK) e Conceitos de POO (Programação Orientada a Objetos)
